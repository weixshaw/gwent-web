# 视觉与动效方向 · Gilded Grimoire（鎏金魔典）· v1.0

> 目标：不是"复刻 W3 原版 UI"，而是**在保留昆特牌辨识度的前提下做一次美术升级**：暗黑奇幻 + 鎏金装饰 + 活页魔典质感 + 电影级动效。整体要"贵、旧、有魔法"。

## 1. 关键词

`obsidian` · `antique gold` · `parchment` · `heraldry` · `runes` · `candlelight` · `faction identity` · `subtle foil`

**避免**：扁平化、亮蓝紫渐变、玻璃拟态、emoji 图标、常规 SaaS 卡片风、过度霓虹。

## 2. 设计 Token（`src/styles/theme.css` 由 Lead 定义，全部模块只用这些变量）

```css
:root {
  /* 底色：黑曜石、焦木、羊皮纸 */
  --ink-0:#070605; --ink-1:#0d0b09; --ink-2:#14100c; --ink-3:#1e1812;
  --paper:#e7dcc2; --paper-dim:#c9bda3; --paper-faint:#8f8570;
  --gold:#c9a227; --gold-bright:#f0d078; --gold-dim:#8a6f22;
  --blood:#7a1f1f; --ember:#ff7a2f;

  /* 阵营色（主色/辉光/点缀） */
  --nr:#4d7ea8;   --nr-glow:#9cc4e4;   /* 北方领域：钢蓝+银 */
  --ng:#c9a227;   --ng-glow:#f0d078;   /* 尼弗迦德：黑金+烈日 */
  --st:#2f7a4a;   --st-glow:#a8e0a0;   /* 松鼠党：森绿+铜 */
  --mo:#8a2323;   --mo-glow:#ff6b5a;   /* 怪物：血红+骨白 */
  --sk:#2f6f6a;   --sk-glow:#9adfd6;   /* 史凯利格：风暴青+青铜 */
  --neutral:#8b7d5c; --neutral-glow:#d9cbb3;

  /* 字体（系统栈，自包含） */
  --font-display: "Palatino Linotype","Iowan Old Style","Songti SC","Noto Serif SC",serif;
  --font-ui: "Avenir Next","PingFang SC","Noto Sans SC",system-ui,sans-serif;
  /* 卡牌尺寸 */
  --card-w: 132px; --card-h: 184px; --card-radius: 10px;
  /* 动效 */
  --ease-out: cubic-bezier(.22,.8,.3,1);
  --dur-fast: 140ms; --dur-mid: 280ms; --dur-slow: 520ms;
  --shadow-deep: 0 18px 44px rgba(0,0,0,.65), 0 2px 8px rgba(0,0,0,.5);
  --shadow-gold: 0 0 18px rgba(240,208,120,.28);
}
```

- 背景：`radial-gradient` 烛光照亮的黑檀桌面 + 细微噪点（SVG filter feTurbulence，低透明度）+ 暗角。
- 金色装饰：1px 描边 + 双层内阴影；关键面板边角放 SVG 花纹（角花）。
- 纸张纹理仅用于卡牌文字区：暖白纸 + 轻微做旧斑点（CSS mask / SVG noise），不整屏泛黄。

## 3. 卡牌设计（visualist 核心）

尺寸比：132×184（约 5:7）。结构自上而下：

1. **外框**：2px 鎏金描边 + 阵营主色内衬；英雄牌为**全金框**+ 底部缎带 + 微光 foil 扫过动画；特殊/天气牌为深色框 + 阵营色符文环。
2. **插画区（约 62% 高）**：**程序化 SVG 生成**（禁止使用版权图）：
   - 每张牌由 `id` 哈希种子决定构图：阵营纹章底 + 生物/角色剪影（抽象徽记化）+ 几何光环/裂纹 + 颗粒/星尘。
   - 阵营纹章：北方=戴冠狮鹫/狮、尼弗迦德=黑日、松鼠党=叶箭、怪物=爪痕骷髅、史凯利格=长船浪纹、中立=八角星。
   - 卡牌 motif 分类（由数据 `art.motif` 或按 id 自动归类）：`monster, beast, warrior, mage, elf, dwarf, vampire, witch, spirit, hero, siege, spell, weather, leader, token`。
   - 插画要"有灵魂"：深色背景里一盏暖光、剪影有体积感；避免纯几何色块。
   - 英雄卡插画额外加金色射线与浮尘；天气牌用动态 CSS 叠加（霜晶/雾/雨丝）。
3. **名称条**：深色半透明缎带，中文名（主，14–15px 衬线，金色描边）+ 英文小字（8–9px，纸灰）。名称过长自动缩小。
4. **能力区**：图标（能力徽记）+ 2–3 行中文能力摘要，纸面质感；悬停时卡片放大并显示完整能力。
5. **力量宝石**：右上角六边形/红宝石底，白/金数字；英雄为金框宝石；力量变化时数字滚动 + 光晕脉冲。
6. **行标记**：左下角小图标（⚔ 近战 / 🏹 远程 / 🏰 攻城 / 灵巧双行 / 天气符文），用自制 SVG，不用 emoji。
7. **背面**：阵营纹章 + 鎏金纹样 + 暗纹，六阵营各一张；牌堆/手牌背面统一。

交互：
- hover：`translateY(-10px) scale(1.06) rotateX(6deg)` 3D tilt（鼠标位置驱动 ±6°），金色高光跟随鼠标；手牌扇形排布，hover 牌抬升、相邻牌让位。
- 可打出：边缘发光；不可打出：灰度 40% + 降低饱和。
- 选中/目标：金框呼吸光 + 角花点亮。
- 入场：从手牌位置飞出（FLIP 或 transform 起终点），落位时轻微下压弹跳 + 尘土粒子。
- 英雄牌有持续的极细微 foil 流光（8s 循环），符合"贵"的感觉但不能闪瞎眼。

## 4. 对局界面布局（Lead 实现，visualist/vfx 配合）

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部：对手横幅（阵营纹章、领袖头像、宝石、分数、手牌数、牌堆数、弃牌堆）│
│ ┌── 对手领袖 ──┐  对手 攻城行（3张并排）                      │
│ │ 领袖卡/能力  │  对手 远程行                                  │
│ │              │  对手 近战行                                  │
│ └──────────────┘  ──────── 天气栏（中央）────────              │
│ ┌── 玩家领袖 ──┐  玩家 近战行                                  │
│ │ 领袖卡/能力  │  玩家 远程行                                  │
│ └──────────────┘  玩家 攻城行                                  │
│ 底部：玩家手牌（扇形） + 分数条 + Pass/提示 + 设置              │
└──────────────────────────────────────────────────────────────┘
```
- 行背景：深色皮革 + 阵营水印纹章（低透明度）+ 行名与行分（左侧竖排小字）。
- 天气栏：5 个天气槽位；激活时对应行叠加粒子层与色调（冰蓝/灰白/雨线/风暴紫青）。
- Pass 后该方面板变暗 + "已放弃" 印章。
- 顶部/底部信息层级要清晰：**分数永远最醒目**（大号衬线数字 + 金色）。

## 5. 全屏特效清单（vfx 实现）

| 时机 | 效果 |
|---|---|
| 主菜单 | 背景余烬粒子 + 雾层 + 缓慢旋转的阵营符文；进入对局时镜头式推进（scale/fade） |
| 抛硬币 | 全屏金币翻面（CSS 3D），落定后金色冲击波 |
| 抽牌 | 卡背从牌堆飞出到手牌 + 微光尾迹 |
| 出牌 | 卡牌沿弧线飞入行，拖尾粒子；落位冲击波；士气/紧缚/号角加成数字逐个浮现 |
| 天气 | 霜：全屏冰晶粒子 + 边缘结霜 + 蓝白闪；雾：多层雾团缓慢流动 + 去饱和；雨：斜向雨丝 + 涟漪；风暴：雨 + 青紫闪电闪屏 + 震动；晴天：金色光斑消散 + 暖光 |
| 号角 | 行中央金色波纹扩散 + 音符/光尘上升 + 行内单位金边 |
| 灼烧 | 火线从中央射向目标 + 目标燃烧溶解 + 余烬上升 + 轻微震屏 |
| 间谍 | 卡牌翻面 + 烟雾中滑向对方行 + 抽牌流光 |
| 医师 | 弃牌堆绿白灵魂光球飞向目标 + 复活光环 |
| 集结 | 多张卡牌分身从牌堆飞出、弧形落位 |
| 复仇者 | 卡牌碎裂成金红色碎片，新卡从碎片中升起 |
| 曼陀罗 | 血红色根须纹路爬过该行 + 变身闪光 + 震动 |
| 领袖能力 | 领袖卡全屏特写 0.5s + 阵营色光爆 + 屏幕暗角 |
| 小局结束 | 分数大字砸入 + 宝石碎裂/点亮 + 胜负印章 |
| 比赛结束 | 胜：金色雨 + 火焰粒子 + 印章；负：暗红余烬 + 缓慢暗场 |
| 其余 | 屏幕闪白/闪金、镜头震动（小幅度）、卡牌被摧毁时的碎片粒子 |

原则：特效**服务于信息**——先让玩家看清发生了什么（卡牌位置、分数变化），再叠氛围；总时长 ≤ 1.2s/事件（大事件 ≤ 2.5s）；可叠加但不可遮挡可点击区域；`prefers-reduced-motion` 时降级为淡入淡出。

## 6. 音效方向（WebAudio 合成，无素材）

- 风格：中世纪奇幻 + 金属质感 + 低频氛围。合成方式：噪声+包络（尘土、雨）、正弦/三角波+滑音（号角、魔法）、金属 808（金币/宝石）、拨弦（卡牌）。
- 音量：SFX 峰值 -14dBFS；环境音 -26dBFS；默认开启但首帧不自动播放（用户点击后 `unlock()`）。
- 对局环境音：低音持续 drone + 偶尔远处雷声/火堆噼啪（音量极低），可静音。
- 关键音：出牌 = 纸牌轻擦 + 落桌闷响；英雄 = 低沉铜管；灼烧 = 火焰轰鸣；天气 = 风声/雷声；小局胜 = 短促凯歌动机（3-4 音）。

## 7. 动效技术约定

- DOM/FLIP + CSS transform/opacity 为主（GPU 友好）；canvas 仅用于粒子层（`position:fixed; pointer-events:none;`）。
- 所有动画包 Promise，超时兜底（`Promise.race` 600–2500ms），任何特效失败不得阻塞游戏。
- 页面不可见时暂停粒子；`prefers-reduced-motion` 降级。
- 帧率：60fps 目标；粒子总数 ≤ 800。
- 不引入外部图片/字体；所有图形 SVG 内联或 CSS 绘制。

## 8. 文案风格

- UI 中文：克制、有质感，不用网络流行语；卡牌能力用「名词：说明」格式（与 W3 中文版一致）。
- 菜单标题可用中英双行：`昆特牌` / `GWENT · THE WITCHER CARD GAME`。
- 阵营名：北方领域 / 尼弗迦德帝国 / 松鼠党 / 怪物 / 史凯利格。
- 关键词统一：近战行 / 远程行 / 攻城行、战力、宝石、弃牌堆、牌堆、领袖、阵营、间谍、医师、集结、紧缚、士气、灵巧、灼烧、复仇者、狂战士、号角、诱饵、曼陀罗、天气、英雄。
